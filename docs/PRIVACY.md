# Privacy / 隐私

## English

The extension reads local Codex lifecycle state, workspace paths and, when available, conversation records to derive project and agent titles. It writes local settings, backups, playback queues and snapshots that may contain private project names and prompt summaries. The extension does not upload these or implement telemetry.

The ToolAI promotion is static bundled content. Only a click opens https://www.toolai.io/ in your browser; that website has its own data practices. The extension uses no remote advertising scripts, automatic website visits or click identifiers. Hide the promotion with its close button or `codexFinishShout.promotion.showToolAI`.

GitHub and Marketplace handle downloads/issues under their own policies. Redact personal data before reporting bugs. Uninstall Backend keeps preferences and backups for recovery; delete these manually only when no longer needed.

## 简体中文

扩展读取本地 Codex 生命周期状态、工作区路径及可用的会话记录，用于生成项目和 Agent 标题；写入本地设置、备份、播放队列和快照，可能包含私人项目名和提示词摘要。扩展不上传这些内容，也未实现遥测。

ToolAI 推广是随包静态内容，仅主动点击时使用浏览器打开 https://www.toolai.io/，网站自身规则另行适用。扩展不加载远程广告脚本、不自动访问网站，也不附加点击标识。关闭按钮或 `codexFinishShout.promotion.showToolAI` 可隐藏推广。

GitHub、Marketplace 的下载和反馈适用各自规则。反馈前请隐藏个人数据。卸载后端保留偏好和备份便于恢复，不再需要时可手工删除。
