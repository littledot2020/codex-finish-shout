## English

Integrated Windows x64 preview with a bundled PowerShell backend, offline player, and three original melodies. Includes project/agent monitoring, English/Chinese UI, initialization/repair/status/uninstall commands, stable music settings and a dismissible ToolAI promotion.

Download the `.vsix` → VS Code Extensions → … → Install from VSIX → **Codex Finish Shout: Initialize Backend** → authorize the lifecycle Hook → reload. Disable the old `local-developer` extension before migrating. Uninstall the backend before removing the extension; personal settings are kept.

Verify downloads with `SHA256SUMS.txt`. See [validation status](https://github.com/littledot2020/codex-finish-shout/blob/main/docs/VALIDATION.md) for tests and remaining manual checks. Local Windows x64 only. Marketplace availability is separate from this GitHub release.

## 简体中文

Windows x64 一体化预览版，内置 PowerShell 后端、离线播放器和三首原创旋律。支持项目／Agent 监控、中英文界面、初始化／修复／状态／卸载命令、稳定音乐设置及可关闭的 ToolAI 推广。

下载 `.vsix` → VS Code 扩展视图 → … → 从 VSIX 安装 → **Codex Finish Shout: 初始化后端** → 完成生命周期 Hook 授权 → 重新加载。迁移前先禁用旧 `local-developer` 扩展；移除扩展前先卸载后端，个人设置保留。

使用 `SHA256SUMS.txt` 校验文件，测试结果和待手工验证项见[验证记录](https://github.com/littledot2020/codex-finish-shout/blob/main/docs/VALIDATION.md)。仅支持 Windows x64 本机。GitHub 已发布不代表商店已上架。
